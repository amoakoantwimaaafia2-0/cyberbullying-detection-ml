## 1. Core paper (the direct source)

| Citation | Task | Dataset | Method | Key Result | Relevance |
|---|---|---|---|---|---|
| Tahmasbi, N. & Rastegari, E. (2018). *A Socio-contextual Approach in Automated Detection of Cyberbullying*. HICSS-51, pp. 1–10. [citation:25] | Binary cyberbullying detection on Twitter | 12,837 English tweets from one celebrity-related incident (607 cyberbullying, 4.7%) | Random forest + four feature groups: textual (LIWC), network centrality, tweet metadata, user metadata. SMOTE for imbalance. 10-fold CV. | User metadata ranked highest by information gain; textual features lowest. All four groups together: cyberbullying recall 62% vs. 32.5% for text alone. **Key claims from the source paper reproduced in this project:**
- Cyberbullying text does not necessarily contain profane language [citation:7][citation:33]
- Non-textual features (user metadata, context) carry more signal than text alone [citation:25][citation:37]
- Combining feature groups outperforms any single group [citation:25]

## 7. Summary: how this project relates to the literature

**Strand 1: Socio-contextual detection.** Tahmasbi & Rastegari (2018) showed on one Twitter incident that user metadata and network position matter more than text. This project tests the same argument on CB2, a conversation-level dataset with different construction.

**Strand 2: Classical ML for cyberbullying.** LR, SVM, and RF with TF-IDF remain standard baselines [citation:5][citation:11]. This project uses all three across three feature sets for a controlled comparison.

**Strand 3: Conversational and contextual datasets.** CB2, SynBullying, and BullyBench all move toward multi-turn, context-aware detection [citation:10][citation:21]. This project uses CB2's conversation structure and tests whether tabular context (peerness, message count, demographics) adds value.

**Gap addressed.** Most comparative studies report a single best model. This project runs a 3×3 grid, reports the full matrix, and adds a paired significance test and bootstrap interval for the one comparison the source paper could not make statistically.
